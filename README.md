# Terraria Ultrawide Patcher for Linux

Графическая версия патчера для Linux x86_64. В архиве поставляется автономный бинарный файл со встроенным .NET runtime; запускать его можно двойным щелчком в файловом менеджере, если оболочка разрешает запуск исполняемых файлов.

## Совместимость

Сборка рассчитана на настольные дистрибутивы Linux x86_64 с glibc 2.27 или новее. Нужны графическая сессия и системные библиотеки X11: `libX11`, `libICE`, `libSM` и `fontconfig`. Wayland-сеанс должен предоставлять XWayland. Архитектуры ARM, musl-дистрибутивы (например, Alpine) и минимальные системы без графической оболочки не поддерживаются.

## Использование

1. Распакуйте архив.
2. Откройте `release/TerrariaUltrawidePatcher`.
3. Выберите `Terraria.exe` в папке игры и нажмите «Применить патч».
4. Перед изменением рядом с игрой создаётся `Terraria.exe.bak`; восстановить исходный файл можно из приложения.

Поддерживаемые сигнатуры соответствуют Terraria 1.4.5.6. Для 32:9/8K включите расширенные лимиты. Если структура файла не совпадает или сигнатуры неоднозначны, патчер ничего не записывает.

## Сборка

Для сборки нужны официальный .NET 8 SDK от Microsoft и `patchelf`. Nix-сборка может включить абсолютные пути окружения хоста, поэтому скрипт отклоняет такой результат.

Из распакованной папки исходников выполните:

```bash
./build-linux.sh
```

Готовый исполняемый файл появится в `release/build-linux-x64/`. В основном репозитории тот же скрипт можно запустить командой `tools/terraria-ultrawide-patcher/build-linux.sh` из корня репозитория; тогда выход останется в `generated-artifacts/`.
